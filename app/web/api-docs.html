API tối giản

PIA CLI + 8/16/20 worker + HAProxy SOCKS5 gateway cố định.

DashboardSwagger

Proxy

socks5h://proxy_user:proxy_password@127.0.0.1:1087

Dùng socks5h:// để DNS cũng đi qua proxy.

Login

curl -X POST http://127.0.0.1:8007/api/login \
  -H "Content-Type: application/json" \
  -d '{"token_1":"EMAIL_OR_USERNAME|PASSWORD","persist":true}'

curl -X POST http://127.0.0.1:8007/api/login \
  -H "Content-Type: application/json" \
  -d '{"token_1":"ACCOUNT_FOR_WORKER_1_TO_20","token_2":"OPTIONAL_SLOT_2","persist":true}'

Mặc định dùng 1 account cho toàn bộ worker. Slot 2 chỉ dùng khi PROXY_WORKERS được cấu hình token_slot 2.

Backend đăng nhập PIA CLI trong worker. Có thể gửi account dạng username|password hoặc dùng field username/password.

Đổi IP mượt phía sau gateway

curl -X POST http://127.0.0.1:8007/api/rotate-any \
  -H "Content-Type: application/json" \
  -d '{"wait_for_ready":false}'

Backend disable worker khỏi HAProxy trước khi rotate, các worker còn lại vẫn phục vụ request mới.

Rotate đúng một container

curl -X POST http://127.0.0.1:8007/api/nodes/worker1/rotate \
  -H "Content-Type: application/json" \
  -d '{"country":"Japan","wait_for_ready":false}'

Tự phục hồi worker

curl -X POST http://127.0.0.1:8007/api/recover \
  -H "Content-Type: application/json" \
  -d '{"force":false}'

curl -X POST http://127.0.0.1:8007/api/nodes/worker1/recover \
  -H "Content-Type: application/json" \
  -d '{"force":true}'

Watchdog cũng tự chạy mỗi HEALTH_INTERVAL_SECONDS giây, endpoint này dùng để kích hoạt thủ công.
